## Live Demo
[emachiptuning.com](https://emachiptuning.com)

## Features
- Chiptuning calculator with a database of 130+ vehicle families and 800+ engine configurations
- Smart service recommendations based on vehicle year, ECU type, and fuel type (DPF, AdBlue, EGR, Pop & Bangs, VAG Coding)
- External vehicle database (`db.js`) decoupled from UI logic
- Dedicated sections for all services: Stage 1 & 2, DPF/EGR/AdBlue OFF, Pop & Bangs, diagnostics
- WhatsApp contact integration and Google Maps embed
- Fully responsive design optimized for mobile devices
- SEO optimization: sitemap.xml, robots.txt, Schema.org JSON-LD, Open Graph meta tags

## Tech Stack
- Vanilla HTML5 / CSS3 / JavaScript (no framework)
- Schema.org AutoRepair structured data (JSON-LD)
- Google Maps Embed API
- Font Awesome 6 + Google Fonts
- Git / GitHub (version control and deployment)

## What I Learned
- Building a multi-section static website without a framework or bundler
- Separating the data layer (`db.js`) from presentation logic
- Implementing an intelligent service recommendation engine based on vehicle characteristics
- SEO optimization for static pages: sitemap, robots.txt, Schema.org, canonical URL
- Responsive design and mobile optimization
